# ADR-0018: 리랭커 점수 하한 재측정 — 노이즈는 해결됐지만 **분할 운**이었다

## 상태

**도입 보류.**

측정은 3단계로 갔고 결론이 두 번 바뀌었다. 순서대로 읽어야 한다.

1. **노이즈는 실제로 마진 아래로 내려갔다** (산포 1.3 → 0.319 vs 마진 0.60).
   ADR-0014의 기각 사유는 해소됐다
2. **쓸 수 있는 쪽은 절대 하한이었다** — 상대 낙폭은 오히려 실패했다.
   착수 전 전제와 반대다
3. **그런데 그 성공이 분할 운이었다.** 분할을 전수 열거하니 안전한 분할이
   72%뿐이고, 실제 쓰던 분할은 상위 83% 백분위였다. **안전과 효용을 동시에
   만족하는 마진이 존재하지 않는다** → 도입하지 않는다

ADR-0014의 기각은 대체하되(**사유가 틀렸다**), 결론(하한을 쓰지 않는다)은
같은 자리로 돌아왔다.

## 배경

ADR-0014는 리랭커 하한을 **기각**했다. 이유는 입력 노이즈가 신호보다 컸다는
것이다 — 같은 절차를 두 번 돌렸는데 홀드아웃 판정이 뒤집혔고(실행 A: 튜닝
−3.59 / 홀드아웃 −4.09, 실행 B: −3.71 / −4.21), 재려던 마진 0.3~0.6에 비해
질의 재작성이 점수를 최대 1.31점 움직였다.

ADR-0017이 그 노이즈의 원인을 잡았다(`temperature` 미설정 → API 기본값 1.0).
**기각의 전제가 사라졌으므로** 다시 쟀다.

## 측정

`scripts/evaluate_rerank_floor.py`에 `--runs N`을 붙였다. 세 가지를 **따로**
잰다 — 서로 다른 질문이기 때문이다.

- **(a) 산포** — 점수가 실행마다 얼마나 흔들리는가 (마진과 같은 단위)
- **(b) 재현성** — **결론**이 실행마다 같은가 (산포가 작아도 임계값이 경계에
  붙어 있으면 결론은 뒤집힌다)
- **(d) 순위 역전** — 부적합이 적합보다 위에 있는가 (있으면 하한으로
  **원리적으로** 못 푼다)

수집 10회(`--runs 5` × 스크립트 2회 실행). 질의 10건 × 상위 8건.

| | 2026-07-30 (기각 시) | 2026-07-31 (재측정) |
|---|---|---|
| 점수 산포 | 0.5 ~ 1.3 | **최대 0.319** (중앙 0.000) |
| 질의 내 마진 | 0.3 ~ 0.6 | 0.60 ~ 2.30 |
| **노이즈 < 마진** | **아니오** | **예** |
| 절차 반복 시 판정 | **뒤집힘** | **10회 전부 동일** |
| 순위 역전 | 있음 | **없음** |

**지난번 깨진 지점을 통과했다.** 전제 조건 판정: 최대 산포 0.319 < 최소 마진
0.60.

산포가 남은 곳은 `"롱소드"` 한 질의에 몰려 있다(0.20~0.32). 나머지 질의는
**중앙값 0.000** — 실행마다 소수점까지 같다.

### 순위 역전은 사라졌다

ADR-0014에 `"단검 보여줘"`에서 `전설 등급 대검`(−3.11)·`+8 롱소드`(−3.35)가
정답인 `미스릴 단검`(−3.64)보다 위에 있다고 적었다. 지금은 `미스릴 단검`이
**1위(−0.31)**이고 부적합은 −2.61부터 시작한다. 10회 수집 전부에서 역전이
하나도 없다.

하드 필터(ADR-0014·0015)와 `temperature=0`(ADR-0017)을 거치며 바뀐 것으로
보이며, 어느 쪽 기여인지는 분리하지 않았다.

## 1차 결론 — 절대 하한 `T = −4.34` (아래 분할 검증에서 뒤집힌다)

**이게 이번 측정의 반전이다.** 착수 시 전제는 "점수가 전부 음수라 절대
임계값은 못 쓰고 상대 낙폭으로 가야 한다"였다. **실측은 정반대였다.**

| 방식 | 임계값 | 튜닝 적합잘림 | 홀드아웃 적합잘림 | 홀드아웃 부적합잘림 |
|---|---|---|---|---|
| **absolute** | **−4.34** | 0 | **0** | **4** |
| relative | 1.63 | 0 | **2** | 8 |

10회 수집 전부 같은 결과다.

### 왜 상대 낙폭이 더 나쁜가

상대 낙폭은 `top1 − score`, 즉 **1위를 기준점으로 정규화**한다. 질의별
차이를 흡수해줄 것 같지만, **그 기준점 자체가 질의마다 크게 다르다.**

| 질의 | top1 |
|---|---|
| 얼음속성 지팡이 | **+2.90** |
| 강화 갑옷 | +1.28 |
| 단검 보여줘 | −0.31 |
| 2만원 이하 전설 등급 무기 | −2.80 |

기준점이 5.7점 범위로 움직이므로, 같은 낙폭 D가 질의마다 전혀 다른 절대
점수 대역을 가리킨다. **움직이는 자에 눈금을 매긴 셈**이라 오히려 전이가 안
된다. 구체적으로 `강화 갑옷`의 `티타늄 판금 갑옷`(적합)이 낙폭 3.23인데
튜닝셋 적합 최대 낙폭은 1.13이라, 튜닝에서 정한 D=1.63이 홀드아웃 적합을
잘랐다.

**"점수가 음수라 절대값을 못 쓴다"는 직관이 틀렸다.** 리랭커 점수는 확률이
아니라 로짓이고 부호에 의미가 없다. 중요한 건 *고정된 수가 적합/부적합을
일관되게 가르는가*이며, 이 코퍼스·이 모델에서는 갈랐다.

### 임의 파라미터(마진)에 대한 민감도

`T = 튜닝셋 적합 최솟값 − 마진`이고 마진은 임의값이라 따로 쟀다.

| 마진 | T | 홀드아웃 적합잘림 | 홀드아웃 부적합잘림 |
|---|---|---|---|
| 0.2 | −4.04 | **0** | 6 |
| 0.5 | −4.34 | **0** | 4 |
| 1.0 | −4.84 | **0** | 2 |

**어느 값에서도 적합 손실이 0이다.** 결론(절대 하한이 쓸 만하다)은 마진에
robust하고 제거 강도만 달라진다. 이 프로젝트에서 임계값을 감으로 정했다가
뒤집힌 전례가 둘(오토인코더 학습셋 편향, 시맨틱 캐시 유사도)이라 확인했다.

## 효과는 크지 않다 — 과장하지 않는다

홀드아웃 부적합 **4/10건(40%)** 제거, 적합 손실 0. 전체로는 14건 중 4건이다.

잘리는 것과 남는 것:

| | 항목 |
|---|---|
| **잘림** | `"단검 보여줘"`의 +7/+8/+9 롱소드(−4.71 ~ −5.12), `"2만원 전설"`의 +6 스틸 해머(−4.98) |
| **남음** | `전설 등급 대검`(−2.61)·`그림자 암살검`(−2.67)·`불꽃의 대검`(−4.08), `가죽 경갑`(−2.54), `"롱소드"` 질의의 부적합 4건 |

즉 **꼬리만 자른다.** 하드 필터가 이미 큰 덩어리를 걷어낸 뒤라(부적합
50 → 14) 하한이 맡을 몫 자체가 작아졌다.

## 2차 검증 — 분할을 전수 열거하니 뒤집혔다

위 1차 결론의 가장 큰 의심은 **"안전성이 분할 운 아닌가"**였다. 10회 반복은
**같은 분할**을 되풀이한 것이라, "노이즈가 줄었다"와 "이 분할에서 우연히
여유가 생겼다"를 구분하지 못한다.

그래서 같은 수집 데이터를 **질의 단위로 다시 나눠 전수 열거**했다
(`--splits`). 추가 API 호출은 없다 — 이미 있는 점수를 재분할할 뿐이다.
결과 0건 질의는 행을 안 남기므로 9질의를 4/5로 나눈 **126가지 전부**.

핵심 통계는 **Δ = 홀드아웃 적합 최솟값 − 튜닝 적합 최솟값**이다.
`Δ > 0`이면 튜닝셋이 더 낮은 적합을 품고 있어 안전하고, `Δ < 0`이면
홀드아웃에 더 낮은 적합이 있어 마진이 `|Δ|`보다 커야 한다.

| | 값 |
|---|---|
| Δ 범위 | **−3.54 ~ +2.17** |
| Δ 중앙값 | **−0.34** (음수) |
| **부등호 유지 (Δ>0)** | **56/126 = 44%** |
| 마진 0.5에서 홀드아웃 적합 손실 0 | **91/126 = 72%** |
| **실제 쓰던 분할의 Δ 백분위** | **83%** |

수집 3회 전부 같은 수치가 나왔다.

**부등호는 절반도 유지되지 않는다.** 실제 쓰던 분할(Δ=+0.34)은 유리한 소수에
속했고 상위 83% 백분위였다. 최악의 분할은 Δ=−3.54로 홀드아웃 적합을
**13건** 자른다.

### 마진을 키워도 안 된다 — 안전과 효용이 양립하지 않는다

"마진을 키우면 되지 않나"가 자연스러운 다음 질문이라 같이 쟀다.

| 마진 | 적합 손실 0인 분할 | 부적합 제거 중앙값 |
|---|---|---|
| 0.5 | 72% | 3건 |
| 1.0 | 72% | 1건 |
| 1.5 | 72% | **0건** |
| 2.0 | 96% | **0건** |
| 4.0 | **100%** | **0건** |

**분할 전체에서 안전해지는 지점(마진 ≥ 4.0)에서는 아무것도 자르지 못한다.**
뭔가 자르는 지점(마진 ≤ 1.0)에서는 분할 넷 중 하나가 적합을 잃는다.
둘을 동시에 만족하는 값이 없다.

### 왜 그런가 — 리랭커 점수는 질의 간에 비교 가능하지 않다

원인은 데이터가 얇아서가 아니라 더 구조적이다.

| | 값 |
|---|---|
| **질의별 적합 최솟값 범위** | −3.84 ~ +2.90 (**폭 6.74점**) |
| 전역 부적합 최댓값 | −2.54 |

적합의 하단이 질의마다 **6.7점** 범위로 움직인다. 전역 임계값이 안전하려면
그중 최악(−3.84)보다 낮아야 하는데, 그 깊이에서는 −2.54 근방의 부적합을 못
자른다. 그리고 "−3.84가 진짜 전역 최솟값인가"는 **어떤 질의를 봤느냐에 전적으로
달려 있다** — 그게 Δ가 분할마다 요동치는 이유다.

이게 상대 낙폭이 실패한 이유(`top1` 기준점이 5.7점 이동)와 **같은 뿌리**다.
크로스인코더 로짓은 한 질의의 후보 집합 안에서만 의미가 있고, **질의를 가로질러
비교할 수 있는 눈금이 아니다.** 절대든 상대든 전역 임계값이 성립하지 않는
근본 이유가 이것이다.

## 알려진 한계

### 0. 효과는 애초에 작았다

1차 결론의 `T=−4.34`도 홀드아웃 부적합 **4/10건**만 잘랐다. 하드 필터가 이미
부적합을 50 → 14로 걷어낸 뒤라 하한이 맡을 몫 자체가 작았다. 즉 **분할 검증을
통과했더라도 얻는 게 크지 않았다** — 보류의 비용이 낮다.

### 1. 튜닝셋이 얇고, 안전성이 운에 기대고 있다 (2차 검증에서 확인됨)

하드 필터 이후 **튜닝셋 부적합은 4건, 전부 `"롱소드"` 한 질의**에서 나온다.
그리고 이번 임계값은 튜닝셋에서 부적합을 **한 건도 못 잘랐다**(효과는 전부
홀드아웃에서 측정됐다). 튜닝셋의 역할은 사실상 "적합 점수 하단이 어디인가"
하나뿐이었다.

더 중요한 건 **안전성의 근거다.** T가 홀드아웃 적합을 안 자른 이유는
튜닝셋 적합 최솟값(−3.84)이 홀드아웃 적합 최솟값(−3.50)보다 **낮았기
때문**이다. 0.34의 여유가 있었다. **이건 분할 운이지 구조적 보장이 아니다** —
2026-07-30에는 정확히 반대였다(튜닝 −3.59 vs 홀드아웃 −4.10). 질의를 늘리면
뒤집힐 수 있다.

### 2. 이 임계값은 이 코퍼스·이 모델에 붙어 있다

`T = −4.34`는 `cross-encoder/mmarco-mMiniLMv2-L12-H384-v1` + 현재 42건
코퍼스에서 나온 값이다. 리랭커 모델이나 코퍼스가 바뀌면 **반드시 재산정**해야
하고, 그게 절대 임계값의 실제 비용이다(상대 낙폭이 매력적으로 보였던 이유이기도
하다 — 다만 위처럼 전이가 더 나빴다).

### 3. 잔여 산포의 출처를 규명하지 않았다

`"롱소드"` 질의에서만 0.20~0.32의 산포가 남는다. 재작성이 그 질의에서
흔들리는지(ADR-0017 측정에서 `"롱소드"`는 문자열 2가지) 다른 요인인지
분리하지 않았다. 마진(0.93) 아래라 이번 결론에는 영향이 없다.

### 4. 표본

질의 10건, 라벨 34건. 홀드아웃 부적합 10건 중 4건 제거라는 수치는 이 크기
위에서 읽어야 한다.

## 결정

**전역 리랭커 점수 하한을 도입하지 않는다.** 절대·상대 둘 다.

기각 사유가 ADR-0014와 **다르다**는 점이 중요하다.

| | ADR-0014 (07-30) | ADR-0018 (07-31) |
|---|---|---|
| 사유 | 입력 노이즈 > 마진 | **질의 간 점수 눈금 비교 불가** |
| 고칠 수 있나 | 예 (ADR-0017이 고쳤다) | **아니오** — 리랭커 점수의 성질이다 |

**다음 사람에게**: 노이즈는 이미 해결됐다. `temperature`를 더 만지거나 재작성을
더 안정시켜도 이 결론은 안 바뀐다. 질의셋을 늘리는 것도 Δ 분포를 더 정확히
추정하게 해줄 뿐 부호를 뒤집어주지 않는다.

### 다시 후보가 되는 조건

- **질의별 점수 정규화가 가능해지면.** 지금 실패의 뿌리가 "질의를 가로지르는
  눈금이 없다"이므로, 질의 내 분포(예: 상위 k개의 평균·표준편차)로 정규화한
  값이 질의 간에 비교 가능한지부터 측정해야 한다. 단, 상대 낙폭이 이미
  그 계열의 순진한 버전이고 실패했다
- **하한이 아닌 다른 컷.** 예: 리랭커 점수 대신 "1위와의 의미적 유사도"처럼
  질의 스케일에 안 묶이는 신호

### 무효가 된 후속 항목

로드맵에 올려뒀던 **"하한 도입 시 0건 처리 구분"**(관련도 미달로 0건이 되면
ADR-0016의 `"조건에 맞는 매물이 없습니다"`가 부정확해지는 문제)은 하한을
안 넣으므로 **발생하지 않는다.** 로드맵에서 내렸다. 다른 이유로 결과를 자르는
기능이 생기면 그때 다시 필요해진다.
