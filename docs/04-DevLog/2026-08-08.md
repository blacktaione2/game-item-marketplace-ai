# 2026-08-08

## 사각지대를 배포본에 태웠고, 라운드가 줄었다

전날 평가셋을 늘리다 찾은 「아이템 어휘를 단 게임 메커니즘 질문」 사각지대를
정면으로 고칠지 정하려고 **먼저 실측**했다. 로컬이 아니라 배포본에 태웠다 —
분류기 가중치가 학습마다 달라 로컬 라우팅은 배포된 동작이 아니다(ADR-0039 기록).

### 8건 중 실제 결함은 2건이었다

| 분기 | 건수 | 결과 |
|---|---|---|
| `faq_smalltalk` | **4** | **이미 올바르게 거절** — 범위를 밝히며 사양, LLM 0회 |
| `compound` | 1 | 되묻는다 |
| `item_search` | 1 | 라벨 보류 (아래) |
| **`price_forecast`** | **2** | **동문서답** — 무관한 아이템의 시세 |

### 2차 방어선이 설계 주장에서 실측으로 바뀌었다

두 동문서답 모두 **진짜 아이템 이름을 밝혔다** (`'+9 강화 롱소드'의 최근 거래가는
29,260원…`). 질의의 주어(`이 옵션`, `세트 효과`)를 채택하지 않았다 — ADR-0039
결정 4가 의도대로 작동한다. **거짓말이 아니라 동문서답**이다.

### 내가 늘린 평가셋에 결함이 있었다

ADR-0039 는 원래 38건에 대해 "어느 분기로 가는지 먼저 무료로 쟀다" 는 단계를
밟았다. **전날 추가한 3건에는 그 단계를 안 밟았다.** 둘이 `faq_smalltalk` 로 가
게이트에 닿지도 않는다.

**그런데 분모에서 뺄 수는 없다.** 로컬/배포 라우팅을 대조하니 **6/8 만 일치**했고
어긋난 둘은 전부 분류기 판정이었다(룰 판정 3건은 완전 재현). *"게이트에 닿는가"*
는 질의의 안정된 속성이 아니다. 그래서 미검출 옆에 **분기를 같이 찍는** 것으로
바꿨다.

> 같은 이유로 ADR-0039 의 커버리지 논증(22+7+9=38/38)도 **분기별로** 읽어야 한다.
> 보장은 "어느 분기로 가든 뭔가가 받는다" 이지 "이 9건이 FAQ 로 간다" 가 아니다.

### 라벨 하나 보류

`강화 확률 올리는 방법 있어?` — *"방법"* 을 물었으니 플레이 질문이라는 읽기와,
거래소의 정직한 답이 "그 확률을 올려주는 물건을 판다" 라는 읽기가 **둘 다
성립한다**(배포본이 성공률 70% 주문서를 돌려줬다). 채점 세트에서 빼고
`AMBIGUOUS_LABEL` 에 이유와 함께 남겼다 — import 가드가 재유입을 막는다.

### 남은 2건은 고치지 않는다

`_forecast_branch` 가 `run_search(size=1)` 의 1등을 **얼마나 약하게 맞았든 그대로
쓴다.** 필요한 건 주제 판정이 아니라 관련성 판정이고, 그건 **ADR-0018 이 이미
기각한 문제**다 — 크로스 인코더 로짓은 한 질의 안에서만 의미가 있다.

근거 셋이 겹쳐서 안 연다: 8건 중 2건, 결과가 거짓이 아님, 기전이 기각된 접근과
겹치고 **해결 방법 자체가 불투명**. 대신 로드맵에 **"ADR-0018 과 같은 뿌리"** 로
등록했다 — 표면이 단순해서("점수 낮으면 버리면 되지") 다시 시작하기 쉬운 문제다.

### 남긴 것

- `AMBIGUOUS_LABEL` + 채점 세트 재유입 방지 가드
- `evaluate_domain_gate.py` — 미검출 옆 분기 표기, "게이트 성적이지 파이프라인
  성적이 아니다" 를 스크립트가 직접 말한다
- ADR-0039 「실측」 절, 로드맵 2건, CLAUDE.md

## 남은 것
